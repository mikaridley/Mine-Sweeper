# Minesweeper Game 🧨

This is my first full-stack bootcamp project! It's a **Minesweeper** game built using **vanilla JavaScript, HTML, and CSS**, with some extra features to make it more fun and interactive.

## Features ✨
- Classic Minesweeper gameplay
- Customizable board size and number of mines
- Highlighted safe tiles when clicking
- Game timer and score tracking
- Responsive design for desktop and mobile

## Technologies Used 🛠️
- HTML
- CSS
- JavaScript (Vanilla JS)
- DOM Manipulation

## How to Play 🎮
1. Open `index.html` in your browser.
2. Click on a cell to reveal it.
3. Right-click to flag a cell as a mine.
4. Try to uncover all safe cells without hitting a mine.
5. Use the timer and flags strategically to win the game!

## Extra Notes 💡
- This project helped me practice **JavaScript logic**, **DOM manipulation**, and **event handling**.
- It’s fully functional without any external libraries or frameworks.
